================================================================================
  MarioRS 精灵资源说明
================================================================================

一、目录结构
--------------------------------------------------------------------------------

assets/
  sprites/              - 原始 Pascal 汇编格式精灵 (DB 格式)
    BROWN.$00           - Pascal include 文本格式 (db 0, 1, 2, ...)
    BROWN.000           - 二进制格式
    MPAL256             - 256色调色板 (6-bit VGA 值)
    ...

  sprites_indexed/      - 转换后的索引 PNG 格式 (由转换工具生成)
    BROWN_000.png       - 灰度 PNG，像素值=调色板索引 (0-255)
    MPAL256.png         - 调色板 PNG (256x1 RGB，已转为 8-bit)
    BOGEN.png           - 背景高度表 (灰度 PNG)
    ...

  BOGEN.BK              - 云层高度表 (Pascal DB 格式)
  BOGEN7.BK             - 另一种云层高度表
  BOGEN26.BK            - Intro 场景云层高度表
  MOUNT.BK              - 山峰高度表


二、资源加载流程
--------------------------------------------------------------------------------

1. 编译时 (include_bytes!)
   - src/sprite_assets.rs 使用 include_bytes! 宏嵌入所有 PNG 文件
   - PNG 二进制数据成为可执行文件的一部分

2. 运行时 (启动时解码)
   - 首次访问精灵时，image crate 解码 PNG
   - 解码结果缓存在 OnceLock 中，后续访问直接使用缓存
   - 像素数据是灰度值，直接作为调色板索引使用


三、精灵格式
--------------------------------------------------------------------------------

1. 原始格式 (Pascal VGA Mode X)
   - 像素数据采用 4-plane 平面布局
   - 每个像素是调色板索引 (0-255)
   - 需要"去平面化"转换为线性 row-major 格式

2. 转换后格式 (索引 PNG)
   - 8-bit 灰度 PNG
   - 像素值直接是调色板索引
   - 启动时 image crate 解码


四、调色板系统
--------------------------------------------------------------------------------

1. MPAL256 (256色全局调色板)
   - 原始: Pascal DB 格式，6-bit VGA 值 (0-63)
   - 转换后: 256x1 RGB PNG，8-bit 值 (0-255)
   - 转换公式: value_8bit = value_6bit * 255 / 63

2. 精灵调色板索引
   - 索引 0: 透明色 (GPU 着色器中 discard)
   - 索引 1-159: 游戏使用的颜色
   - 其余索引: 保留/未使用

3. 动态变色逻辑
   - figures.rs 中的 recolor/recolor2/replace 函数
   - 直接操作像素的调色板索引值
   - 例如: 将 Mario 精灵的红色索引替换为绿色索引得到 Luigi


五、转换工具
--------------------------------------------------------------------------------

1. 转换脚本: convert_sprites.cmd
   - 双击运行或命令行执行
   - 调用 cargo run --example convert_to_indexed_png

2. 转换工具: examples/convert_to_indexed_png.rs
   - 解析 Pascal DB 格式
   - 执行 Mode X 去平面化
   - 输出灰度 PNG (精灵/背景) 和 RGB PNG (调色板)

3. 构建流程
   a) 首次构建前运行 convert_sprites.cmd 生成 sprites_indexed/
   b) cargo build 直接编译，PNG 通过 include_bytes! 嵌入
   c) 如果修改了原始精灵，需重新运行转换脚本


六、GPU 渲染
--------------------------------------------------------------------------------

1. 纹理格式
   - 精灵图集: R8 格式 (单通道，存储调色板索引)
   - 调色板纹理: RGBA8 格式 (256x64，多行用于动画)

2. 着色器采样 (sprite.wgsl)
   - 从精灵纹理采样得到调色板索引
   - 使用索引从调色板纹理获取最终颜色
   - 支持 palette_offset 实现运行时变色

3. 调色板动画
   - PaletteGenerator 生成淡入淡出/闪烁帧
   - 64行调色板纹理存储不同动画状态


七、精灵尺寸
--------------------------------------------------------------------------------

常规精灵 (20x14):
  BROWN, PIPE, GREEN, SAND, GRASS, BRICK0-2, COIN, EXIT, ...

角色精灵 (20x28):
  SJMAR, LJMAR, FWMAR, FJMAR (Mario)
  SJLUI, LJLUI, FWLUI, FJLUI (Luigi)

敌人精灵:
  CHIBIBO (20x14), GRKOOPA/RDKOOPA (20x24), PPLANT/HIT (24x20)

特殊精灵:
  FIRE/PART (12x7), INTRO (108x28, 24x28, 84x28), START (116x13, 108x13)


八、文件说明
--------------------------------------------------------------------------------

src/sprite_assets.rs   - PNG 嵌入和解码模块
src/sprites.rs         - 精灵数据管理
src/backgr.rs          - 背景渲染和高度表访问
examples/convert_to_indexed_png.rs - Pascal DB 到 PNG 转换工具
convert_sprites.cmd    - Windows 转换脚本
build.rs               - 仅处理 Windows 图标嵌入
